# Conversor de unidades

Programa sencillo de escritorio para convertir velocidades entre km/h y m/s usando ventanas de Java Swing.

## Requisitos
- JDK instalado.
- No requiere librerías externas

## Compilar y ejecutar

Desde la carpeta raíz del proyecto, ejecuta en PowerShell:

```powershell
javac -d out src/ConversorUnidades.java
java -cp out ConversorUnidades
```
